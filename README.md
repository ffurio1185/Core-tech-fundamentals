Task 3 – Chunking

Topic: DNS – Domain Name System

To make the DNS topic easier to understand and remember, I divided the information into 7 meaningful chunks.

Chunk 1 – What is DNS?

DNS stands for Domain Name System. Its main purpose is to translate human-readable domain names into IP addresses that computers can use.

Example:
example.com → DNS → IP address

Chunk 2 – Domain Names

A domain name is an easy-to-remember name used to access a website. It is easier for people to remember a name such as example.com than a numerical IP address.

Chunk 3 – IP Addresses

An IP address identifies a device or service on an IP network. DNS helps find the IP address associated with a domain name so that the computer can contact the appropriate server.

Chunk 4 – DNS Query

When I enter a domain name into my browser, my computer needs to find its IP address. A DNS query is used to request this information.

In simple form:

Domain name → DNS query → IP address

Chunk 5 – DNS Servers

Different DNS servers can participate in finding the answer.


DNS resolver: receives the DNS request and searches for the answer.
Root server: helps direct the resolver toward the appropriate top-level domain.
TLD server: provides information about domains under extensions such as .com, .org or .de.
Authoritative name server: provides the authoritative DNS information for the requested domain.


Chunk 6 – Connecting to the Website

After DNS returns the appropriate IP address, the computer can use that address to contact the destination server.

A simplified process is:

Enter domain name → DNS lookup → IP address found → connect to server → website can be requested

Chunk 7 – DNS Problems

If DNS is not working correctly, a website may not be reachable by its domain name even though the computer has a network connection.

This helps me understand that having a network connection and having working DNS are two different things.

Why I Chose These Chunks

I divided DNS into these seven chunks because each chunk represents one important part of the topic. Learning the information in smaller groups makes it easier for me to understand the complete DNS process and remember how the different parts are connected.
